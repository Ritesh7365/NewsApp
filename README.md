# SpaceNews

News app for iPhone made with SwiftUI. Shows the latest space news using the free Spaceflight News API.

Made this for the networking part of my iOS learning.
<img width="398" height="818" alt="image" src="https://github.com/user-attachments/assets/d9554c32-d273-4fc0-abb2-be2cdd0cda0c" />

## Features
- latest news list with images
- search news
- pull to refresh
- loads more when you scroll down
- article detail screen with share and "read full article"
- error screen with retry when there's no internet

## Built with
- Swift, SwiftUI
- URLSession with async/await
- Codable for JSON
- MVVM

API: https://api.spaceflightnewsapi.net/v4/articles/ (no key needed)

## Run
Open `SpaceNews.xcodeproj` in Xcode, pick an iPhone simulator and press Cmd+R.
